Syntax:
title: Name (servings)
prereq: prep step text (multiple lines = multiple rows above the table)
ingredients: ingredients section, each line: id = *amount* description | note
  *asterisks* bold a fragment (e.g. the amount), | note is a gray annotation, append #optional at the end to mark it optional.
steps: steps section, each line:
id: input1, input2 -> Step label | details (time, notes)
  an input can be an ingredient id or an earlier step's id. The step's column and cell height (row span) are computed automatically from the union of its inputs' spans.

Auto-arrange: if a step only uses A and C (with B in between), the app automatically moves ingredients so A and C become adjacent — without touching your source text, only the rendering. If two steps have genuinely conflicting order requirements, the remaining "gap" is shown as a hatched cell (instead of looking like the step uses that ingredient).
